# المهمة 93 — الاستعادة التلقائية بعد التوقف القسري وملكية التشغيل التفاعلي

## الهدف

استعادة كل محادثة كانت تعمل قبل Force Stop أو تعطل العملية أو انقطاع الطاقة إلى تشغيل طبيعي قابل للإيقاف والتوجيه، من دون إعادة تنفيذ أثر أداة ذي نتيجة مجهولة تلقائيًا.

## القرارات المثبتة والنطاق

- كل work item صالح الملكية وكان `running` أو `resuming` يُستعاد تلقائيًا؛ الحظر يقتصر على بيانات تالفة أو ملكية غير قابلة للإثبات.
- طلب مزود انقطع قبل حفظ رده يعود تلقائيًا إلى `checkpoint_before_model_request` الموثوقة ثم يستأنف.
- الأداة التي بدأت ولم تحفظ نتيجة نهائية لا يعاد تنفيذها تلقائيًا؛ يُحفظ لها tool result محايد يوضح أن النتيجة غير معلومة وأن على النموذج التحقق قبل تقرير إعادة التنفيذ.
- نتائج الأدوات المكتملة تُستعاد كما هي، والأدوات التي لم تبدأ أصلًا في batch يمكن تنفيذها مرة واحدة.
- سؤال المستخدم أو طلب الإذن غير المجاب يبقى `waiting`. بعد الإجابة يُستكمل عبر `ActiveRun` العادي بحيث يعمل Stop وSteer وحراس النشر.
- قبول القرار وانتقال work item وحفظ القرار القابل للاستعادة يجب أن تكون ذرية.
- لا يعتمد الحل على تجاهل أحداث صحيحة في الواجهة؛ يمنع الـAgent الأحداث المتأخرة، مع دفاع Client ثانوي ضد run تم إيقافه إن لزم.
